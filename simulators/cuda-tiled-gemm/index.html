Naive: each thread walks a full row of A and column of B, 4 × 32 = 128 global loads. Tiled: 8 phases × 8 cooperative loads = 64, and every value staged in s_A / s_B is consumed by 2 threads. For the whole 16×16 GEMM that is 8,192 naive vs 4,096 tiled global loads.

Naive: every thread walks global memory

      
One thread per output element. Thread (ty, tx) streams a whole row of A and column of B straight from global memory, the slow “main pantry”.

      

      
    
        
  • Per thread: 16 + 16 = 32 global loads; per 2×2 block: 128.
    • 
        
  • T(0,0) and T(0,1) both fetch the same row of A; across the grid every element of A and B is fetched 16 times.
    • 
        
  • Whole GEMM: 2·N³ = 8,192 loads for only 512 distinct values.
    • 
      

      
Counts here are global load requests. On real GPUs the L1/L2 caches absorb part of the naive kernel's redundancy (a 16×16 problem fits entirely in L2); shared memory makes the reuse explicit and guaranteed.

    

    

      
Tiled: load, sync, compute, sync

      
The block fetches a 2×2 tile of A and of B once into shared memory (the “workbench”), then every thread computes from there.

      
    
        
  • Load: thread (ty, tx) fetches exactly one A and one B element, so 8 global loads per phase.
    • 
        
  • __syncthreads(): nobody reads the tiles until all 8 loads have landed. (With TILE = 2 the 4 threads form one warp that moves in lockstep; the staggered arrivals in the demo show what happens in larger, multi-warp blocks.)
    • 
        
  • Compute: acc += s_A[ty][i] · s_B[i][tx] for i = 0, 1, served from shared memory.
    • 
        
  • __syncthreads(): nobody overwrites the tiles while a neighbour is still reading them.
    • 
      

      

        
Global memory (DRAM)Visible to every block. Hundreds of cycles per access.

        
Shared memory (SRAM)Per block, on-chip. ~20–30 cycles per access.

      

    

    

      
Reuse grows with the tile size

      
With TILE = T, each staged value feeds T threads, so global loads fall to 2·N³ / T. This demo uses T = 2; production kernels use 16–32 (or larger, register-blocked tiles).

      

      
Shared memory per block is 2·T²·4 B: 2 KB at T = 16, 8 KB at T = 32. For this one-thread-per-output kernel the real cap is threads per block (T² ≤ 1024, so T ≤ 32); register-blocked kernels use bigger tiles, where shared-memory capacity and occupancy become the limit.
